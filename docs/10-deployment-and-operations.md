# 教育广告 CRM 数据分析平台部署与运维设计

## 1. 文档目的

本文档定义平台环境规划、部署拓扑、配置管理、数据库迁移、日志监控、备份恢复、安全运维、虚拟账户清理、发布回滚和日常运维要求。

## 2. 环境规划

### 2.1 本地开发环境

用于开发和单服务调试：

- Docker Compose 启动 PostgreSQL、Redis、对象存储。
- Go 和 Python 服务可本地单独启动。
- 前端 Vite 开发服务器。
- 使用 Mock 广告平台或沙箱凭证。

### 2.2 测试环境

用于功能测试、契约测试和集成测试：

- 独立 PostgreSQL。
- 独立 Redis。
- PGMQ 队列初始化。
- 自动执行数据库迁移。
- 使用测试对象存储桶。
- 使用沙箱广告平台或录制回放数据。

### 2.3 预发布环境

用于生产前验收：

- 与生产接近的服务拓扑。
- 连接广告平台真实或准真实环境。
- 数据使用脱敏样本或授权测试租户。
- 执行性能、回归和回滚演练。

### 2.4 生产环境

用于正式客户：

- API 网关统一入口。
- Go 服务和 Python 服务容器化部署。
- PostgreSQL 高可用。
- Redis 高可用。
- 对象存储持久化。
- worker 按 PGMQ 队列独立部署和扩容。

## 4. 配置管理

配置来源：

- 环境变量。
- 密钥管理服务。
- 配置服务。
- Kubernetes Secret 或 Docker Secret。

敏感配置不得写入代码仓库，包括：

- 数据库密码。
- Redis 密码。
- 广告平台 app secret。
- OAuth token 加密密钥。
- 对象存储密钥。

## 5. 数据库迁移

### 5.1 迁移原则

- 所有 schema 变更必须通过迁移脚本。
- 迁移脚本必须可审查。
- 生产迁移必须先在预发布环境执行。
- 高风险迁移需要回滚方案。
- BI 指标和数据集变更需要版本号。

### 5.2 迁移顺序

1. 发布向后兼容数据库字段。
2. 发布服务代码。
3. 回填或 ETL 重算。
4. 切换新字段或新指标版本。
5. 清理旧字段或旧逻辑。

## 6. 日志与追踪

### 6.1 日志字段

所有服务日志应包含：

- `timestamp`
- `level`
- `service`
- `env`
- `trace_id`
- `request_id`
- `tenant_id`
- `user_id`
- `message`
- `error`

### 6.2 业务日志

需要记录：

- 线索导入开始和结束。
- 广告同步开始、结束和失败。
- ETL 批次结果。
- BI 刷新结果。
- 报表生成结果。
- 虚拟账户清理结果。

### 6.3 链路追踪

API 请求、PGMQ 消息和后台任务应传递同一个 `trace_id`，便于定位跨服务问题。

## 7. 监控与告警

### 7.1 服务监控

- 服务存活。
- 响应时间。
- 错误率。
- CPU、内存、磁盘。
- 容器重启次数。

### 7.2 数据库监控

- 连接数。
- 慢查询。
- 锁等待。
- 表膨胀。
- 索引命中率。
- 复制延迟。

### 7.3 Redis 监控

- 内存使用。
- key 过期。
- 命中率。
- 连接数。
- 慢命令。

### 7.4 PGMQ 监控

- 队列长度。
- 消息延迟。
- 消费成功率。
- 重试次数。
- 死信或失败消息数量。

### 7.5 业务告警

- 广告同步连续失败。
- ETL 批次失败。
- BI 刷新失败。
- 报表生成失败。
- 虚拟账户清理失败。
- 租户数据隔离异常。
- 虚拟账户即将过期但存在未完成迁移。

## 8. 备份与恢复

### 8.1 PostgreSQL

- 每日全量备份。
- 持续归档 WAL。
- 定期恢复演练。
- 备份加密存储。

### 8.2 对象存储

- 开启版本或生命周期策略。
- 区分正式租户和虚拟账户路径。
- 虚拟账户销毁时删除对应文件。

### 8.3 Redis

Redis 主要存储缓存和短期状态，不作为长期数据来源。必要状态应可从 PostgreSQL 重建。

## 9. 安全运维

- 全站 HTTPS。
- 服务间通信使用内网或 mTLS。
- 数据库最小权限账号。
- 密钥定期轮换。
- OAuth token 加密存储。
- 文件上传限制类型、大小和扫描策略。
- 审计日志不可由普通业务用户删除。

## 10. 虚拟账户运维

### 10.1 过期任务

定时任务扫描虚拟账户：

- 距过期 24 小时提醒。
- 到期后投递清理消息。
- 清理失败进入告警。

### 10.2 清理验证

清理后必须验证：

- PostgreSQL 业务表无该虚拟租户业务数据。
- Redis 无该虚拟租户 key。
- 对象存储无该虚拟租户文件。
- PGMQ 无可识别的未处理虚拟账户消息。
- 仅保留清理审计。

## 11. 发布策略

### 11.1 常规发布

1. 合并代码。
2. 运行自动化测试。
3. 构建镜像。
4. 部署测试环境。
5. 部署预发布环境。
6. 执行冒烟测试。
7. 灰度生产流量。
8. 全量发布。

### 11.2 回滚策略

- 服务镜像支持快速回滚。
- 数据库迁移必须有回滚或兼容方案。
- BI 指标版本可回退。
- 扩展包可按租户禁用或回滚。

## 12. 容量规划

第一阶段按中小规模租户设计：

- PostgreSQL 优先优化索引、分区和读副本。
- 广告原始报表可按日期和租户分区。
- ETL 和 BI worker 可独立横向扩容。
- Redis 用于热点缓存，不承载不可恢复数据。
- PGMQ 队列按业务拆分，避免互相阻塞。
