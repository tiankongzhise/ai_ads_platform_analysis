# 教育广告 CRM 数据分析平台前端设计

## 1. 文档目的

本文档定义平台前端技术选型、信息架构、核心页面、用户旅程、BI 配置体验、状态处理和设计系统落地方案。

## 2. 技术选型

前端采用：

- React。
- TypeScript。
- Vite。
- Ant Design Pro。
- ECharts。

选择理由：

- 适合中后台管理和 BI 分析场景。
- Ant Design Pro 提供成熟布局、表格、表单和权限菜单能力。
- ECharts 适合复杂数据可视化和中文业务场景。
- TypeScript 有助于维护 API 契约和 BI 配置类型。
- Vite 开发体验快，适合模块化前端工程。

## 3. 前端应用范围

第一阶段以前端 Web 管理端为主，覆盖：

- 登录后主框架接入既有鉴权。
- 组织、团队、渠道配置。
- 广告账户与同步状态。
- 线索导入、线索列表、冲突处理。
- 标准 BI 看板。
- 付费 BI 配置。
- 报表生成与下载。
- 虚拟演示账户创建、销毁和迁移。

## 5. 核心用户旅程

### 5.1 正式租户首次使用

```text
进入系统
  → 查看示例或空态引导
  → 创建组织结构
  → 创建招生团队
  → 配置广告渠道
  → 接入广告账户
  → 上传线索或接入 API
  → 查看冲突识别结果
  → 查看标准 BI
  → 生成报表
```

### 5.2 日常管理

```text
登录
  → 集团总览
  → 查看异常指标
  → 下钻到学校、团队、渠道
  → 处理冲突线索
  → 导出报表或分享看板
```

### 5.3 销售演示

```text
创建虚拟演示账户
  → OAuth2 临时授权广告账户
  → 同步最近数据
  → 展示 BI 看板
  → 客户确认后授权迁移到正式账户
  → 或现场销毁虚拟账户
```

## 6. 页面设计

### 6.1 集团总览

展示集团整体招生进度、广告消耗、线索数量、报名结果和 ROI。

核心组件：

- 指标卡片。
- 近 7 天或近 30 天趋势图。
- 组织层级汇总表。
- 渠道 ROI 排行。
- 异常提示和行动建议。

### 6.2 学校对比

用于不同学校、校区或子组织之间效果对比。

核心功能：

- 组织筛选。
- 时间范围筛选。
- 指标对比表。
- 柱状图或散点图。
- 下钻到学校详情。

### 6.3 团队效率

展示各招生团队线索上报、有效线索、到校、报名和成交效率。

核心功能：

- 团队排行。
- 漏斗转化。
- 冲突量占比。
- 团队详情。

### 6.4 渠道 ROI

展示抖音、腾讯、百度、小红书等渠道表现。

核心功能：

- 渠道花费。
- 线索成本。
- 报名成本。
- ROI。
- 平台账户同步状态提示。

### 6.5 招生漏斗

展示线索、有效沟通、到校、报名、成交等阶段转化率。

核心功能：

- 漏斗图。
- 阶段转化表。
- 按团队、渠道、课程筛选。

### 6.6 线索冲突

用于管理多团队重复咨询。

核心功能：

- 冲突组列表。
- 冲突详情。
- 主咨询选择。
- 冲突裁定审计。
- 冲突处理效率统计。

### 6.7 线索导入

支持 Excel 上传和字段映射。

核心状态：

- 上传前：模板下载和上传引导。
- 解析中：进度提示。
- 映射确认：字段映射和数据预览。
- 导入中：处理进度。
- 完成：成功、重复、失败统计和错误报告下载。

### 6.8 广告账户

展示各平台账户和同步状态。

核心功能：

- 平台分组。
- 账户状态。
- 最近同步时间。
- 同步失败原因。
- 手动同步。
- 断开或重新授权入口。

### 6.9 BI 看板配置

付费用户可配置：

- 指标显示隐藏。
- 图表类型。
- 位置和大小。
- 筛选器。
- 角色视图。

界面必须只暴露受控目录，不提供 SQL 输入框。

### 6.10 报表中心

核心功能：

- 报表列表。
- 创建报表任务。
- 下载报表。
- 查看行动建议。
- 查看生成状态和错误信息。

### 6.11 虚拟演示账户

核心功能：

- 创建虚拟账户。
- 显示剩余有效期。
- 接入临时广告数据。
- 手动销毁。
- 授权迁移到正式账户。
- 查看清理审计结果。

## 7. 状态与反馈设计

所有数据展示组件应支持：

- 加载态。
- 空态。
- 部分数据态。
- 完整数据态。
- 错误态。

空态不应只显示“暂无数据”，应提供下一步行动，例如：

- 去创建组织。
- 去配置团队。
- 去绑定广告账户。
- 去上传线索。
- 查看演示数据。

## 8. BI 可视化规范

### 8.1 图表类型

- 指标卡：核心 KPI。
- 折线图：趋势。
- 柱状图：组织、团队、渠道对比。
- 漏斗图：招生阶段转化。
- 热力图：小时趋势或交叉分析。
- 表格：明细和排行。

### 8.2 数据口径提示

BI 页面应展示：

- 时间范围。
- 归属规则。
- 数据更新时间。
- 指标口径说明入口。
- 是否使用缓存。

## 9. 设计系统落地

参考 `md/edu-adcrm-ui-design-system.md`，但需要按实际产品调整。

### 9.1 风格

- 专业、清晰、可信赖。
- 面向中后台和 BI，不做营销型落地页。
- 信息密度适中，优先支持管理者扫描和比较。

### 9.2 颜色

- 使用稳健的主色和语义色。
- 广告平台可使用平台识别色，但不得让页面变成单一平台主题。
- 错误、警告、成功状态必须有清晰语义。

### 9.3 组件

优先使用 Ant Design Pro 组件：

- Layout。
- Menu。
- ProTable。
- ProForm。
- Modal。
- Drawer。
- Tabs。
- Segmented。
- DatePicker。
- Tree。
- Tooltip。

图标优先使用项目已选图标库或 Ant Design Icons。
