## 🎨 设计稿规范

### 画板尺寸

| 平台 | 尺寸 | 说明 |
|------|------|------|
| Web 桌面端 | 1920 × 1080 | 主流桌面分辨率 |
| Web 平板端 | 1024 × 768 | iPad 横屏 |
| Web 移动端 H5 | 375 × 812 | iPhone X |
| 小程序 | 375 × 812 | 微信小程序标准 |

### 栅格系统

```
桌面端（≥1024px）:
├── 容器最大宽度: 1440px
├── 栅格列数: 24列
├── 栅格间距: 24px
└── 边距: 48px

平板端（768-1023px）:
├── 容器最大宽度: 100%
├── 栅格列数: 16列
├── 栅格间距: 16px
└── 边距: 24px

移动端（<768px）:
├── 容器最大宽度: 100%
├── 栅格列数: 4列
├── 栅格间距: 12px
└── 边距: 16px
```

### 标注规范

**元素标注内容**：
```
┌─────────────────────────────────┐
│                                │
│    Title Label                 │
│    字号: 16px / 颜色: #333333  │  ← 标注示例
│    间距: 8px                   │
│                                │
└─────────────────────────────────┘
```

**标注必填项**：
- 尺寸（宽 × 高）
- 内边距
- 字体（字号、字重、颜色）
- 间距（margin/padding）
- 圆角
- 阴影

## 🔗 快捷操作

### 创建设计文件（模板）

如需创建新的 Figma 文件，可复制以下结构：

```
文件名称: EduAdCRM - [页面名称] v1.0

Frame 尺寸: 1920 × 1080 (桌面端)

包含内容:
├── Header (64px)
├── Sidebar (240px)
└── Content Area (自适应)
    ├── Page Header (64px)
    └── Page Content (自适应)
```

### 导出组件规范

1. **Figma 导出**：
   - 选中组件 → 右键 → "Export"
   - 格式选择: PNG/SVG
   - 勾选 "Include id"

2. **蓝湖导出**：
   - 进入标注模式
   - 点击 "导出标注"
   - 选择导出格式（CSS/iOS/Android）
